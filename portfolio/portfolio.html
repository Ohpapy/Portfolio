Simulation Cisco Packet Tracer

En Réseaux, j'ai pu apprendre les différents types de configuration ainsi que le paramétrage des différents équipements. Nous avons principalement vu le matériel Cisco. Nous pouvons voir ici le lien vers un fichier .pkt qui est l'extension du logiciel Cisco Packet Tracer qui nous permet de simuler un réseau sans aucun matériel. Dans ce fichier, vous trouverez la configuration d'un réseau pour une petite entreprise (avec une connexion avec un serveur web et dns). Pour le réseau local les ip sont distribuée par un serveur DHCP. Le réseau local de l'entreprise est protègé par un fire wall qui ce nomme ASA 5505.

Projet Multi-site

Dans ce projet multi-site, nous avons configuré deux routeurs, quatre MLS (Multi-Layer Switches), quatre switchs et un ASA (Adaptive Security Appliance). Les routeurs ont été configurés pour assurer la connectivité entre les différents sites, tandis que les MLS et les switchs ont été utilisés pour gérer le trafic interne et optimiser les performances du réseau.

L'ASA a été mis en place pour fournir une couche supplémentaire de sécurité en filtrant le trafic entrant et sortant, protégeant ainsi le réseau contre les menaces externes. Cependant, la configuration détaillée de l'ASA n'est pas incluse ici.

Ce projet m’a également permis d’approfondir plusieurs aspects liés à la cybersécurité, notamment la compréhension des mécanismes de filtrage du trafic, la gestion des accès, ainsi que les bonnes pratiques pour sécuriser un réseau. J’ai ainsi pu acquérir des notions essentielles pour protéger efficacement un site contre les différentes menaces potentielles.

Boucle Locale Orange

Le domaine de la boucle locale chez Orange concerne principalement les réseaux de télécommunications reliant les abonnés finaux aux infrastructures du réseau. Ce travail exige une combinaison de compétences techniques, relationnelles et organisationnelles pour garantir la qualité et la continuité des services proposés par l'opérateur.

Les techniciens de la boucle locale travaillent principalement sur le terrain, avec des déplacements fréquents pour intervenir directement chez les clients ou sur les équipements de réseau. Ils doivent également être disponibles pour des astreintes en cas de pannes urgentes.

Pour vous expliquer, ici nous avons effectués une intervention sur un câble 900 paires donc un cable cuivre, qui se situe à Saint-Laurent-du-Var. Plusieurs clients étaient en panne car le câble était imbibé d'eau. Nous avons changé les raccords et nous avons pu rétabli les clients.

Test d'intrusion

Qu'est-ce qu'un pentest ?

Un pentest (ou test d'intrusion) est une méthode utilisée pour évaluer la sécurité d’un système informatique en simulant une attaque réelle. L’objectif est d’identifier les vulnérabilités exploitées par des pirates (malwares, failles réseau, erreurs de configuration, etc.), et de proposer des solutions concrètes pour les corriger avant qu’un véritable attaquant ne les découvre.

Résumé du projet

Dans le cadre d’un projet universitaire, un test d’intrusion a été réalisé sur deux machines. L’objectif était d’identifier les vulnérabilités présentes et de proposer des mesures correctives. Deux principales failles ont été découvertes : une vulnérabilité critique sur une version obsolète de Samba (CVE-2017-7494), permettant un accès root à distance, et une faille d’injection de commande sur une application web DVWA.
